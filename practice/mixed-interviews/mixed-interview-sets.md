# Mixed Interview Sets

Use this file for multi-round Data Engineering interview practice.

Mixed sets should combine technical correctness, communication, project depth, and recovery from follow-ups.

## Set A: Early-Career Data Engineer

Expected time: 60 minutes

```text
1. SQL: latest order per customer with tie-breaker.
2. Python: deduplicate event dictionaries and keep latest event.
3. Fundamentals: explain idempotency with a failed rerun example.
4. System design: design a daily batch pipeline.
5. Project: explain one project with personal contribution.
```

## Set B: SQL and Python Screen

Expected time: 45 minutes

```text
1. SQL: top 3 products by monthly revenue.
2. SQL follow-up: include products with zero revenue.
3. Python: parse records, validate required fields, aggregate invalid counts.
4. Python follow-up: handle large input without loading everything.
```

## Set C: Product-Company Data Engineering Round

Expected time: 75 minutes

```text
1. SQL: retention or funnel query.
2. DSA: Top K Frequent Elements.
3. System design: clickstream analytics pipeline.
4. Project deep dive: architecture, data quality, and failure handling.
5. Behavioral: production incident or unclear requirements.
```

## Scoring

Score each area from 0 to 5:

| Score | Meaning |
|---:|---|
| 0 | Not attempted |
| 1 | Major gaps |
| 2 | Basic but not interview-ready |
| 3 | Usable with support |
| 4 | Interview-ready for many rounds |
| 5 | Strong, handles follow-ups |
