## 32. SQL Interview Answer Guardrails

For SQL problems:

```text
1. Restate the requirement.
2. Identify grain.
3. Identify required tables.
4. Decide joins.
5. Build step-by-step CTEs.
6. Use window functions where needed.
7. Explain edge cases.
8. Mention performance if relevant.
```

Common mistakes to avoid:

```text
joining without understanding grain
using DISTINCT to hide duplicates
forgetting NULL handling
using wrong date filter
not handling ties
not explaining approach
```

SQL explanation template:

```text
First I create the base rows at the required grain.
Then I apply filters.
Then I aggregate/rank/deduplicate.
```
