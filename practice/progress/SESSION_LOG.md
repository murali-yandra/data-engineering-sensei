## 1. Purpose

The session log helps the AI mentor and candidate answer:

```text
What did we do last time?
What files were created?
What topic was practiced?
What score did the candidate get?
What weakness was found?
What was assigned next?
Which files were updated?
```

Use this file to prevent:

```text
lost progress
repeated work
forgotten weaknesses
unclear next steps
false sense of progress
```

Do not use this file for:

```text
long project documentation
full mock feedback transcripts
full weakness details
complete resume bullet history
```

Those belong in their dedicated progress files.

## 3. Session Status Values

Use these status values:

```text
completed:
session finished and output exists

partial:
session started but not fully finished

blocked:
session could not continue

cancelled:
session intentionally stopped

needs_followup:
session completed but requires next action

retest_required:
session found weakness that must be retested
```

Do not use vague labels:

```text
good
done maybe
almost
reviewed
learned
```

## 8. Logging Rules

Log a session when:

```text
a file is generated
a drill is completed
a mock interview is completed
a score is assigned
a weakness is discovered
a weakness is repaired
a project milestone is completed
resume/GitHub is reviewed
roadmap phase changes
job search action happens
```

Do not log:

```text
casual questions
small definitions
unrelated chat
temporary thoughts
```

Rule:

```text
If it changes readiness or progress, log it.
```


## 9. Score Logging

When a session includes scoring, record:

```text
score out of 5
pass/fail
rubric used
why score was given
main missing points
retest requirement
```

Score entry template:

```text
Score:
3/5

Why:
Candidate understood basic architecture but missed idempotency, monitoring, and DQ gates.

Pass:
no

Retest:
yes, after repair drill.
```

Rule:

```text
A score without explanation is not useful.
```


## 10. Weakness Logging


## 18. Session Review Questions

After each session, ask:

```text

2. Did it change any score?
3. Did it reveal a weakness?
4. Did it repair a weakness?
5. Did it update the roadmap?
6. Did it create a next step?
7. Did it affect resume/project/job readiness?
8. Which files must be updated?
```

If all answers are no:

```text
The session probably does not need a detailed log.
```
