# Python Drills Index

This is the canonical Python practice index for Data Engineering Sensei.

Python practice should use realistic data engineering inputs, not isolated syntax trivia.

## Default Drill Flow


## Required Skills

The candidate must be able to:

- use list, dict, set, tuple
- parse nested records
- process CSV/JSON-like data
- aggregate records
- deduplicate records
- keep latest record by timestamp
- handle missing fields
- write clean functions
- explain complexity
- use pandas only when appropriate
- add basic logging and error handling when the task requires it

## Review Checklist

Check:

1. Correctness.
2. Input assumptions.
3. Edge cases.
4. Time and space complexity.
5. Readability.
6. Function boundaries.
7. Error handling.
8. Avoidance of unnecessary nested loops.
9. Appropriate data structure choice.
10. Interview explanation.
