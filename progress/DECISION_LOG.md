## Current Decisions

### Public Reusable Skill

Decision:

```text
Data Engineering Sensei must be reusable and neutral. It should not hardcode one candidate's project, market, location, stack, or job search status.
```

Reason:

```text
The skill is intended for public use by many early-career data professionals.
```

Impact:

```text
Templates should use placeholders and examples. Candidate-specific data belongs only in progress files after a candidate provides it.
```

### Job-Focused Scope

Decision:

```text
The skill includes interview preparation, project proof, resume evidence, public portfolio readiness, and professional profile/job-search preparation.
```

Reason:

```text
Interview readiness for early-career Data Engineering candidates often requires proof, not just concept study.
```

Impact:

```text
Career asset support is allowed, but it must remain evidence-based and optional.
```
