# Weakness Register

Use this file to track weaknesses that require repair before interview readiness.

A weakness should be added only when there is evidence from an answer, drill, mock, code review, SQL review, system design review, project deep dive, resume review, or portfolio review.

## Severity

```text
Critical: likely interview failure
High: serious risk
Medium: needs improvement
Low: polish
```

## Repair Rule

Do not close a weakness because the candidate read an explanation. Close it only after the candidate passes an exit test.
