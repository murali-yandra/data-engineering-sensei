# Python Answer Framework

Use this template for Python coding answers in Data Engineering interviews.

## Before Coding

```text
1. Clarify input shape.
2. Clarify output shape.
3. Ask about malformed or missing data.
4. State brute-force idea if useful.
5. State optimized approach.
6. Choose data structures.
7. Mention complexity target.
```

## Answer Structure

```text
Assumptions:

Approach:

Code:

Complexity:

Edge cases:

Follow-up handling:
```

## Review Checklist

- correct result
- clean function boundaries
- readable variable names
- correct dict/set/list use
- no unnecessary nested loops
- handles empty input
- handles missing or malformed fields when relevant
- explains time and space complexity
- avoids pandas unless expected
