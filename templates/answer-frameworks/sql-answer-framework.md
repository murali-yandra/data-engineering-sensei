# SQL Answer Framework

Use this template to structure SQL interview answers.

## Before Writing SQL

```text
1. Restate the business question.
2. Identify the output grain.
3. Identify the base table.
4. Identify joins and duplicate risk.
5. Identify filters and date boundaries.
6. Decide whether aggregation is needed before or after joins.
7. Decide whether window functions are needed.
8. Mention edge cases.
```

## Answer Structure

```text
Approach:

SQL:

Explanation:

Edge cases:

Performance notes:

Validation:
```

## Review Checklist

- output grain stated
- correct join type
- no accidental duplicate explosion
- correct aggregation level
- correct window partition/order
- NULL handling
- date boundaries
- readable CTEs
- candidate can explain logic
