# Session Summary Template

Use this template at the end of a session when the candidate wants progress tracking.

```text
Date:
Session type:
Target role:
Current module:
Difficulty:

What was practiced:

Candidate performance:

Scores:
SQL:
Python:
DSA:
Fundamentals:
System design:
Project:
Communication:

Mistakes observed:

Corrections given:

Evidence created:

Weaknesses added or updated:

Next task:

Exit criteria before moving on:
```

Progress should be evidence-based. Do not mark a topic complete because it was merely discussed.
